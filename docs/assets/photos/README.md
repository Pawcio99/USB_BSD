# Galeria — opublikowane, zweryfikowane pliki

Nie umieszczaj tutaj nieprzejrzanych zrzutów ani surowych fotografii.
Docelowy materiał: zoptymalizowany `.webp`, bez EXIF/XMP i danych osobistych.
Limit walidatora: 5 MiB / plik. Nazwy zgodne z `assets/photos/[a-z0-9_-].(png|jpg|jpeg|webp)`.
Dodanie zdjęcia wymaga też nowego wpisu w `docs/data/gallery.json`.
Szczegóły: [instrukcja galerii](../../GALLERY.md).

Zdjęcia pozostają nieopublikowane do czasu dostarczenia ich przez autora i kontroli prywatności.
